Ans2. Workflow -
(i). Quality Control and Pre-processing : Running tools such as fastqc (QC check on reads)/MultiQC, fastp/Trimmomatic (adapter trimming), etc.
(ii). Alignment tools and Quantification : Using STAR to GRCh38 and then featureCounts.
(iii). Sample level QC : PCA on variance-stabilized counts to check clustering by disease, batch, sex or age.
(iv). Running differential expression tools - Such as DESeq2. Filter low-count genes first.
(v). Compare each disease against controls, then intersect the DE genes with an UpSet plot, keeping only genes that change in the same direction.
(vi). Enrichment using GSEA and databases such as KEGG.

Limitations - 
No healthy controls are mentioned. 
n=6 per group gives low power, thus giving unstable results and inflated effect sizes.
Enrichment results depends heavily on the background set.
No validation cohort, so there is a need of public data to confirm.

c) The heatmap suggests one group differs from the other two, rather than a signature common to all three diseases. A common signature would show the same genes changing in the same direction in all groups, so I'd test that directly, for example by comparing each disease against controls and intersecting the results. With n=6 and some heterogeneous samples, the results are exploratory and need validation by qPCR or a public dataset.
Since the genes were selected because they differ between groups, the clean separation is expected. I'd confirm by running an unsupervised PCA.
